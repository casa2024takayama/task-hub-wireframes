# タスクハブ（Personal Task Hub）

並行プロジェクトが多い人向けの **個人用タスク・プロジェクト管理 PWA**（React / Vite）。メールやチャットで飛んでくる小さな依頼を、まず受信箱に捕獲してからプロジェクトへ振り分ける想定です。

## 公開トップページ（ダッシュボード）

**https://casa2024takayama.github.io/task-hub-wireframes/**

（GitHub Pages 経由の本番ビルド。ルート `/` は上記のパスがトップです。）

## 主な機能（ざっくり）

- **ダッシュボード** — 貼り付け欄から受信箱へ保存、直近の「小タスク」帯、プロジェクトカード（締切順・再開メモ・タスクの一部表示）
- **受信箱** — 未振り分けのメモ。タスク化してプロジェクトに紐づけ／未割当でも保存可。長文は AI による振り分け提案（環境設定による）
- **プロジェクト** — 締切・再開メモ（URL は自動リンク）、タスク（サイズ・締切・依頼者・コピペ元の参照）、アイテムリスト、完了／再開
- **レポート** — 完了数・滞留・プロジェクト別の消化と期限の表示など
- **設定** — バックアップのエクスポート／インポート、データ消去、バージョン表示（必要に応じて Firebase 連携）

詳細な仕様の一次情報はリポジトリ内の [`mvp-spec.md`](./mvp-spec.md) を参照してください。

## ローカル開発

```bash
npm install
npm run dev
```

開発サーバは `http://localhost:5300`（`vite.config.ts` の設定どおり）。

```bash
npm run build
```

型チェックと本番ビルドを実行します。
